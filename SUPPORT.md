## 3. Issue Triage & Reporting Process

When opening an issue, please choose the appropriate issue template:
1. **Bug Report:** Use this when a script crashes, fails to produce expected output, or triggers an unhandled exception.
2. **Scientific Claim Dispute:** Use this if you believe an empirical claim, catalyst benchmark, or chemical equation in the database contains an error or conflict with primary literature.
3. **Feature Request:** Use this to propose new dataset columns, additional pathway dossiers, or new CLI flags.
4. **Question:** Use this for clarification regarding data definitions, metric normalization math, or installation hurdles.
